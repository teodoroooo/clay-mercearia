# Jorge Clay Mercearia — Sistema Integrado

> Projeto acadêmico de desenvolvimento de software com metodologia Scrum.

## 📋 Sobre o projeto

Sistema integrado para a **Jorge Clay Mercearia**, uma rede de 5 lojas que vende produtos importados da China e deseja expandir para vendas online via WhatsApp, mantendo o controle centralizado de vendas, estoque e operações de caixa físico.

### Módulos previstos

1. **Vendas via WhatsApp** — atendimento ao cliente, bot de respostas automáticas, catálogo, pagamentos e rastreamento de origem.
2. **Controle de Estoque** — gestão multi-loja, alertas de estoque baixo, integração com kanban existente.
3. **Sistema de Caixa (PDV)** — operação das lojas físicas, emissão de nota fiscal, fechamento de caixa.

Todos os módulos sincronizam dados via **servidor central**.

## 🌳 Estrutura de branches

- `main` — código de produção, estável
- `develop` — integração das features
- `feature/<nome-da-feature>` — desenvolvimento de novas funcionalidades
- `bugfix/<nome-do-bug>` — correções

## 📝 Padrão de commits

Seguimos o padrão [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` nova funcionalidade
- `fix:` correção de bug
- `docs:` documentação
- `test:` testes
- `refactor:` refatoração de código
- `chore:` tarefas de manutenção

Exemplo: `feat: adiciona cadastro de produtos no estoque`

## ✅ Definition of Done

Um card só é considerado "concluído" se:

- [ ] Código no repositório, na branch correta
- [ ] Testes escritos e passando
- [ ] Code review aprovado por outro membro
- [ ] Critérios de aceite todos cumpridos
- [ ] Documentação atualizada (se aplicável)
- [ ] Product Owner validou a entrega
